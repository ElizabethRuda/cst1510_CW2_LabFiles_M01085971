================================================================================
TABLE DESCRIPTIONS:
================================================================================

USERS
  Purpose: Stores user authentication and authorization information
  Constraints:
    - username must be unique
    - password_hash stores bcrypt hashed passwords
    - role defaults to 'user' (can be 'admin', 'analyst', 'user')

CYBER_INCIDENTS
  Purpose: Tracks security incidents and their resolution status
  Constraints:
    - severity: Critical, High, Medium, Low
    - status: open, in_progress, resolved
    - date: ISO format string (YYYY-MM-DD)

DATASETS_METADATA
  Purpose: Catalog of datasets with metadata for data governance
  Constraints:
    - name is required
    - size stored in bytes (can be converted to GB/MB)
    - source and category are optional

IT_TICKETS
  Purpose: IT support ticket tracking system
  Constraints:
    - priority: critical, high, medium, low
    - status: open, in_progress, resolved, closed
    - created_date: ISO format string

Note: Current implementation does not enforce foreign key relationships,

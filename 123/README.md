# Intelligence Platform Dashboard

Веб-приложение для визуализации данных платформы Intelligence Platform, построенное на Streamlit.

## Возможности

- 📊 **Главная страница** - обзор ключевых метрик и быстрые графики
- 🛡️ **Кибер-инциденты** - детальная визуализация инцидентов безопасности с фильтрами
- 📚 **Метаданные датасетов** - анализ датасетов по категориям, источникам и размерам
- 🎫 **IT-тикеты** - управление и визуализация IT-тикетов
- 📈 **Общая статистика** - комплексный анализ всех модулей

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запустите приложение:
```bash
streamlit run app.py
```

Приложение откроется в браузере по адресу `http://localhost:8501`

## Структура данных

Приложение автоматически создает базу данных SQLite в папке `DATA/intelligence_platform.db` и генерирует примерные данные для демонстрации, если база данных пуста.

### Таблицы базы данных:

- **users** - пользователи системы
- **cyber_incidents** - кибер-инциденты
- **datasets_metadata** - метаданные датасетов
- **it_tickets** - IT-тикеты

## Использование

1. Откройте приложение в браузере
2. Используйте боковое меню для навигации между разделами
3. На страницах с данными используйте фильтры для уточнения результатов
4. Изучайте интерактивные графики и таблицы

## Технологии

- **Streamlit** - фреймворк для веб-приложений
- **Plotly** - интерактивная визуализация
- **Pandas** - обработка данных
- **SQLite** - база данных

## Примечания

- Данные автоматически генерируются при первом запуске
- Все графики интерактивны - можно масштабировать, фильтровать и изучать данные
- Приложение использует кэширование для оптимизации производительности

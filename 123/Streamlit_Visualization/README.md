# Intelligence Platform - Enhanced Visualization Dashboard

Улучшенное веб-приложение для визуализации данных платформы Intelligence Platform с использованием Streamlit и Plotly.

## 🎯 Особенности

- ✅ **Интеграция с существующей структурой проекта** - использует модули `app/data` и `app/services`
- ✅ **Система аутентификации** - регистрация и вход с валидацией
- ✅ **Интерактивные визуализации** - графики Plotly с фильтрами
- ✅ **Работа с реальными данными** - подключение к существующей базе данных SQLite
- ✅ **Многомодульный дашборд** - инциденты, датасеты, тикеты и аналитика

## 📁 Структура проекта

```
Streamlit_Visualization/
├── Home.py              # Страница входа/регистрации
├── auth.py              # Функции аутентификации
├── pages/
│   └── Dashboard.py     # Главный дашборд с визуализациями
├── requirements.txt     # Зависимости
└── README.md           # Документация
```

## 🚀 Установка и запуск

### 1. Установите зависимости

```bash
cd /home/stud/123/Streamlit_Visualization
pip install -r requirements.txt
```

### 2. Убедитесь, что база данных существует

Приложение ожидает базу данных по пути:
```
/home/stud/123/DATA/intelligence_platform.db
```

Если база данных еще не создана, запустите скрипты из основной структуры проекта для создания таблиц и загрузки данных из CSV.

### 3. Запустите приложение

```bash
streamlit run Home.py
```

Приложение откроется в браузере по адресу `http://localhost:8501`

## 📝 Примечания

- Данные загружаются из базы данных SQLite
- Аутентификация использует session state (для продакшена рекомендуется использовать базу данных)
- Все графики интерактивны - можно масштабировать, фильтровать и изучать данные
- Приложение автоматически обновляет данные при каждом обращении

## 🐛 Решение проблем

### Ошибка подключения к базе данных
Убедитесь, что:
- База данных существует по пути `DATA/intelligence_platform.db`
- Таблицы созданы (запустите `app/data/schema.py`)
- Данные загружены из CSV файлов

### Ошибка импорта модулей
Убедитесь, что:
- Структура проекта `app/data/` существует
- Все необходимые файлы на месте
- Python path настроен правильно

# 📦 Инструкция по обновлению Git репозитория

## Что в архиве

Архив `Intelligence_Platform_Basic.zip` содержит **Light Mode версию** проекта с белым дизайном и полной функциональностью.

### Структура архива:
```
temp_export/
├── app/                    # Модули для работы с БД
│   ├── data/              # CRUD операции
│   └── services/          # Бизнес-логика
├── DATA/                  # CSV файлы и данные
├── Streamlit/            # Streamlit приложение
│   ├── Home.py           # Страница входа
│   ├── Dashboard.py      # Дашборд (базовая версия)
│   └── auth.py           # Функции аутентификации
├── requirements.txt      # Зависимости
├── README.md             # Документация
└── .gitignore           # Git ignore файл
```

## Как обновить Git репозиторий

### Шаг 1: Распакуйте архив
```bash
unzip Intelligence_Platform_Basic.zip
```

### Шаг 2: Перейдите в папку
```bash
cd temp_export
```

### Шаг 3: Проверьте структуру
```bash
ls -la
```

Должны быть папки: `app/`, `DATA/`, `Streamlit/`

### Шаг 4: Обновите Git репозиторий

#### Вариант A: Если это новый репозиторий
```bash
git init
git add .
git commit -m "Initial commit: Intelligence Platform basic version"
git branch -M main
git remote add origin <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
git push -u origin main
```

#### Вариант B: Если репозиторий уже существует
```bash
# Добавьте все файлы
git add .

# Закоммитьте изменения
git commit -m "Update: Add Intelligence Platform basic version"

# Отправьте в репозиторий
git push origin main
```

## Запуск приложения


### 2. Запустите приложение
```bash
cd Streamlit

```

### 3. Войдите в систему
- **Логин:** `admin`

3. **Структура:** Сохранена оригинальная структура проекта из архива `cst1510_CW2_LabFiles_M01085971-main.zip`.

4. **Дизайн:** Это базовая версия без космического дизайна. Все функции работают, но интерфейс простой.

## Если что-то не работает

1. Проверьте, что все зависимости установлены:
   ```bash
   pip install -r requirements.txt
   ```

2. Убедитесь, что база данных создана:
   - При первом запуске она создастся автоматически
   - Или запустите скрипты из `app/data/schema.py`

3. Проверьте пути к файлам:
   - Убедитесь, что вы запускаете из папки `Streamlit/`
   - Пути к `app/` и `DATA/` должны быть корректными

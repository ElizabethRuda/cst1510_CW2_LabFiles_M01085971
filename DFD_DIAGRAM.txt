DATA FLOWS:
================================================================================

User ──[Login Credentials]──> 1.0 AUTHENTICATION
1.0 AUTHENTICATION ──[Session State]──> Dashboard
1.0 AUTHENTICATION ──[Read Request]──> D1 (users)

User ──[Domain Selection]──> 2.0 DATA RETRIEVAL
2.0 DATA RETRIEVAL ──[Read Request]──> D1
D1 ──[Domain Data]──> 2.0 DATA RETRIEVAL
2.0 DATA RETRIEVAL ──[Domain Data]──> 3.0 DATA VISUALIZATION
2.0 DATA RETRIEVAL ──[Domain Data]──> 5.0 DATA ANALYSIS

3.0 DATA VISUALIZATION ──[Charts]──> User
5.0 DATA ANALYSIS ──[Insights]──> User

User ──[AI Query]──> 4.0 AI PROCESSING
4.0 AI PROCESSING ──[API Request]──> OpenAI API
OpenAI API ──[AI Response]──> 4.0 AI PROCESSING
4.0 AI PROCESSING ──[AI Response]──> User

D2 ──[CSV Data]──> 6.0 DATA LOADING
6.0 DATA LOADING ──[Database Records]──> D1

================================================================================
DFD - Level 2 (Detailed Process: 3.0 DATA VISUALIZATION)
================================================================================

Domain Data ──> [Data Transformer] ──> Formatted Data
Formatted Data ──> [Chart Generator] ──> Plotly Figures
Plotly Figures ──> [Chart Renderer] ──> Interactive Charts

Chart Types:
  - Pie Charts (Severity, Status, Category distribution)
  - Bar Charts (Counts by category)
  - Line Charts (Timeline trends)
  - Histograms (Size distributions)

================================================================================
KEY DATA FLOWS SUMMARY:
================================================================================

1. Authentication Flow:
   User → Login → Verify Password (bcrypt) → Session State

2. Data Display Flow:
   User → Select Domain → Query Database → Process Data → Generate Charts → Display

3. AI Interaction Flow:
   User → Enter Query → Add Context → Call OpenAI API → Process Response → Display

4. Data Loading Flow (Initialization):
   CSV Files → Read Data → Validate → Insert into Database
